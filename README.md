СТО Диспетчерская система
Веб-приложение для автоматизации работы станции технического обслуживания (СТО).

Функциональные возможности:
~ Управление клиентами
- Добавление, редактирование, удаление клиентов
- Просмотр списка клиентов
- Привязка паспортных данных

~ Управление автомобилями
- Добавление автомобилей к клиентам
- Хранение госномера, VIN-кода, марки, модели, года, цвета
- Просмотр всех автомобилей в системе

~ Управление работниками
- Ролевая модель: Администратор и Работник
- Администратор: полный доступ к работникам, архиву, аналитике
- Работник: доступ только к своим данным и работе с клиентами

~ Управление ремонтами
- Создание заказов-нарядов
- Добавление услуг из прайс-листа
- Добавление дефектов
- Расчёт стоимости автоматически
- Завершение ремонта и отправка в архив

~ Прайс-лист (25 услуг)
- Диагностика
- Двигатель
- Подвеска/Тормоза
- Трансмиссия
- Электрика
- Кондиционер

~ Аналитические отчёты
1. Кто обслуживал владельца автомобиля
2. Самая частая неисправность марки
3. Лучший работник по выработке
4. Устранённые неисправности клиента
5. Владельцы по типу неисправности

~ Счета и документы
- Формирование счёта после завершения ремонта
- Печать акта выполненных работ
- Отслеживание статуса оплаты

Технологический стек:
~ Backend
- Node.js + Express
- TypeScript
- PostgreSQL
- JWT аутентификация
- bcrypt для хеширования паролей

~ Frontend
- React 18
- TypeScript
- Vite
- Axios
- React Router DOM
